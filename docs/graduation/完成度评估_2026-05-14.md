## 已完成的主要内容

### 功能层面

- **多格式解析**：PDF（文本层 + OCR 增强）、Word、Excel、PPT、图片、TXT/MD/JSON/CSV
- **OCR 链路**：RapidOCR + Tesseract 双引擎，候选结果评分选优，图片预处理与缓存，自适应税号补强
- **发票结构化提取**：11 个核心字段，可扩展字段模板机制，多票据类型支持
- **数据管理**：SQLite 持久化，分页查询，单条/全部删除，CSV 导出
- **批量评测**：样本集 + 评测脚本，字段级准确率报告，Markdown/JSON/CSV/HTML 输出

### 工程层面

- 5 层分层架构：入口层 → 路由层 → 服务层 → 核心解析层 → 数据持久层
- Docker 镜像配置，Render 云部署配置
- 6 个单元测试文件，覆盖 OCR 变体选择、发票字段合并、回归测试等
- 11 个脚本工具，包含批测、评测、样本生成、毕业材料生成

### 今日 UI 改动（2026-05-14）

- 模板编辑器：删除所有英文 kicker、说明段落、pill 标签、底部 hint，弹窗标题缩小，padding 收紧
- 识别设置栏：发票识别、发票记录、发票模板三块统一为同一 `opts-section`，标题类统一，删除按钮移至底部一行
- 新增功能：保存状态文字改为可点击链接，点击后自动展开发票记录面板并高亮对应条目

## 论文建议表述

**系统定位（推荐）：**

> 本系统以 Python 为主要开发语言，基于 Flask 构建 Web 服务，围绕多格式文档自动化处理场景，实现了 PDF、Word、Excel、PPT、文本文件和图片文件的统一解析流程；同时结合 OCR 技术和规则化信息抽取方法，实现了发票关键信息的结构化提取、存储、查询和导出，并通过样本集和评测脚本对系统效果进行了验证。

**可重点强调的创新点：**

- 多格式文档统一解析流程
- PDF 文本层解析与 OCR 增强结合
- 多 OCR 引擎候选评分选优机制
- 面向发票字段的规则化结构提取
- 税号等关键字段的跨引擎融合修复
- 样本驱动的批量评测体系

**需要避免的表述：**

- 不写"成熟商用系统"或"生产级系统"
- 不把自建样本集的高准确率泛化为所有场景
- 不宣称"适用于所有复杂真实发票场景"
