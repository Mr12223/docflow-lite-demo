# 课题功能与创新点

## 课题名称

基于 Python 的多格式文档自动化处理与内容提取工具设计

## 项目概述

本项目是一个面向多类型办公文档的自动化处理工具，支持用户上传 PDF、Word、Excel、PPT、文本文件和图片文件，系统自动完成文档解析、OCR 识别、内容提取、结构化信息抽取、结果展示和批量评测。

项目以 Python 为主要开发语言，后端基于 Flask 实现 Web 服务，前端提供文件上传、处理进度展示、识别结果查看和批量测试入口。

## 主要功能

1. 多格式文档解析：支持 PDF、Word、Excel、PPT、TXT、Markdown、JSON、CSV 等格式。
2. 图片 OCR 识别：支持对图片和扫描类文档进行文本识别。
3. 文本内容提取：提取文档正文、表格、元数据、关键词和摘要信息。
4. 发票信息抽取：从文档或 OCR 文本中提取发票号码、日期、金额、购销方、税号等字段。
5. 发票记录管理：支持发票信息保存、查询、删除和 CSV 导出。
6. 异步任务处理：支持文件处理进度轮询和任务取消。
7. 批量测试评测：支持样本集批量运行，并生成 Markdown、JSON、CSV、HTML 等报告。
8. 部署运行支持：支持本地运行，并提供 Docker 和云部署配置。

## 创新点

1. 统一多格式文档处理流程，屏蔽不同文件格式之间的解析差异。
2. 采用多 OCR 引擎回退与候选结果评分机制，提高图片文本识别稳定性。
3. 引入面向业务字段的结构化提取方法，实现从非结构化文本到字段化数据的转换。
4. 针对发票税号等易错字段设计跨引擎融合与修复策略，提高关键字段提取准确率。
5. 建立样本驱动的批量评测体系，使系统处理效果可以量化分析和对比。
6. 采用分层架构设计，将路由、服务、解析、OCR、数据库等模块解耦，提高系统可维护性。

## 总结

本项目围绕多格式文档自动化处理场景，完成了从文件上传、内容解析、OCR 识别、结构化提取到结果管理和批量评测的完整流程，具有较好的实用价值和本科毕业设计完成度。
